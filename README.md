# AI 기사 제작·발행 시스템

신설 언론사를 위한 수집·검증·작성·편집·발행 파이프라인의 기획 및 구현 저장소입니다.

## 목표
- 공공기관·기업 보도자료와 허용된 공개 외신 피드를 모니터링하고 출처·시각을 보존합니다.
- AI는 출처 기반 초안과 근거를 생성하고, 기자가 검토·승인한 뒤 CMS에 게시합니다.
- 1단계 보도자료 기사화에서 데이터·리서치 기사로 확장 가능한 구조를 마련합니다.

## 초기 원칙
1. 초기 버전의 외부 발행은 사람 승인 필수입니다. CMS 자동 게시는 승인 이후에만 실행합니다.
2. 원문 복제·번역을 피하고 사실 확인, 출처 표시, 인용 제한, 저작권·이용약관을 점검합니다.
3. 모든 초안은 근거 링크, 원문 발췌, 주장별 신뢰도와 변경 이력을 가집니다.
4. 비밀값은 저장소에 넣지 않고 환경 변수/비밀 저장소로 관리합니다.
