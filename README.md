# AI 기사 제작·발행 시스템

신설 언론사를 위한 수집·검증·작성·편집·발행 파이프라인 기획 및 구현 저장소입니다.

## 목표
- 공식 보도자료와 사용 허가된 외신 피드 수집
- 근거가 연결된 기사 초안 생성 및 편집자 승인 후 CMS 발행
- 보도자료에서 외신·데이터·리서치 기사로 단계적 확장

## 초기 원칙
- 초기 외부 발행은 사람 승인 필수
- 출처·저작권·이용약관·인용 기준 준수
- 기사 주장마다 근거와 편집 이력 보존
- 비밀값을 저장소에 커밋하지 않음
