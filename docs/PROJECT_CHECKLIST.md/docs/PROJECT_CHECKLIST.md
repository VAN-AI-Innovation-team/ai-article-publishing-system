# 프로젝트 체크리스트

## 착수 및 CMS
- [ ] sheerit 관리자 권한 승인 확인 (hanms1017)
- [ ] CMS API, 초안·예약 게시·미디어 기능 확인
- [ ] 사이트 수정 필요사항과 2-5 조정 범위 기록
- [ ] 개인별 계정, MFA, 최소 권한 확인
- [ ] 편집 규정·기사 샘플의 사용권리 확인

## 편집·출처
- [ ] 독자·주제·기조·기사 유형별 문체 확정
- [ ] 출처·인용·정정·민감 주제 확인 절차 수립
- [ ] 공공기관은 공식 RSS/API, 외신은 허가된 피드 우선
- [ ] 라이선스·이용약관·robots.txt·수집 빈도 검토
- [ ] 원문 URL, 게시/수집 시각, 기관, 저자 기록

## MVP
- [ ] 수집·정규화·중복 제거·분류·우선순위
- [ ] 주장별 근거 링크를 갖춘 기사 초안
- [ ] 편집기와 승인/반려, 변경 이력
- [ ] 승인 이후 sheerit CMS 업로드, 게시 상태/실패 기록
- [ ] 권한·감사로그·비밀값·백업 관리
